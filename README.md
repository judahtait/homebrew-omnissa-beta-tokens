# judahtait/omnissa-beta-tokens (Homebrew tap)

Homebrew tap for [Omnissa Beta Token Utility](https://github.com/judahtait/omnissa-beta-tokens).

```bash
brew tap judahtait/omnissa-beta-tokens
brew install --cask omnissa-beta-token-utility
```

Release assets live on the app repository; bump `version` and `sha256` in `Casks/omnissa-beta-token-utility.rb` when shipping a new build.
